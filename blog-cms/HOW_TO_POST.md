# How to add a blog post (no coding needed)

1. Go to the admin page (ask whoever set this up for the link — it
   looks like `https://forward-blog-cms.something.workers.dev/admin/`).
2. Enter the admin password and click دخول (Log in).
3. Click **+ منشور جديد** (New post).
4. Fill in:
   - **العنوان** (Title) — the post's headline.
   - **رابط الصفحة (slug)** — fills in automatically from the title.
     You can leave it as-is.
   - **مقتطف قصير** (Short excerpt) — one or two sentences that show up
     on the blog's main page, under the title.
   - **اسم الكاتب** (Author name).
   - **صورة الغلاف** (Cover image) — click to upload a photo from your
     computer, or paste an image link instead.
   - **محتوى المقال** (Content) — the full text of the post. Use the
     small toolbar above the text box (غامق/bold, مائل/italic,
     عنوان/heading, رابط/link, صورة/image, قوائم/lists, اقتباس/quote)
     to format it — select some text and click a button, or click a
     button and type. Click **👁 معاينة** (Preview) any time to see how
     it will actually look.
5. Flip the **نشر المقال** (Publish) switch on when you want it to go
   live immediately. Leave it off to save as a draft you can finish
   later — drafts are only visible here in the admin page, never on
   the public site.
6. Click **حفظ** (Save).

That's it — a published post appears on `/blog` on the main site
within a few seconds, with no need to wait for anyone to redeploy the
website.

To edit or unpublish a post later, log in, find it in the list, click
**تعديل** (Edit), make your changes (or flip the publish switch off),
and save. To remove one for good, open it and click **حذف المقال**
(Delete post) at the bottom of the editor.
